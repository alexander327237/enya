# Бот бригады для мессенджера Макс

Программа для Windows: подключает бота в Максе к нейросети (GigaChat, YandexGPT или любой
OpenAI-совместимой — Ollama, LM Studio и др.). Работает на вашем компьютере, ключи хранятся только у вас.

## Запуск

1. Скачайте `dist/brigade-bot.exe` и положите в отдельную папку (рядом появится файл настроек
   `brigade-bot-config.json`).
2. Запустите. Откроется браузер с панелью `http://127.0.0.1:8765`. Чёрное окно не закрывайте — это и есть бот.
3. **Макс:** business.max.ru → Чат-боты → создать бота → ⋮ → Настройки → скопировать токен →
   вкладка «Макс» → вставить → «Сохранить» → «Запустить».
4. **Нейросеть:** вкладка «Нейросеть» → выбрать провайдера → вставить ключ → «Сохранить и проверить».
5. **Доступ:** напишите боту в личку `/id`. На вкладке «Статус» в «Ожидают разрешения» нажмите «Разрешить».
   Добавьте бота в чат бригады и тоже разрешите чат.

Windows может предупредить «неизвестный издатель» — «Подробнее» → «Выполнить в любом случае».

## Как пользоваться в чате

- `бот, вопрос` — обычный вопрос (в личке слово «бот» не нужно).
- Ответ на сообщение бота — продолжение разговора.
- `/смета …`, `/материалы …`, `/акт …`, `/тендер …`, `/клиенту …` — режимы (меняются на вкладке «Команды»).
- `/помощь`, `/сброс`, `/лимит`, `/id`.
- **Вложения**: фото и картинки уходят нейросети как есть (нужна модель со зрением, например `deepseek-flash`),
  PDF/Word/Excel/CSV/текст — текстом, голосовые — расшифровкой от Макса, видео — кадром-превью.
  В группе бот смотрит вложение, если есть обращение (в подписи или в голосовом), в личке — всегда.
  Для PDF нужен `pdftotext` (`sudo apt install poppler-utils`), для старых .doc/.xls — LibreOffice.

## Табель

- `/пришёл [объект]` и `/ушёл` — бот запишет время и посчитает часы (смена через полночь тоже считается).
- `/часы 8 [объект]` — внести вручную, `/часы 8 вчера` — за вчера.
- `/табель` — часы за месяц по людям и объектам, `/табель прошлый` — за прошлый месяц.
- В панели вкладка «Табель»: правка записей, добавление часов за другого, выгрузка для Excel.
  Данные лежат в `brigade-bot-timesheet.json` рядом с программой.

## Защита

- Бот отвечает только разрешённым людям и чатам; остальные получают отказ без обращения к нейросети.
- Дневные лимиты запросов на человека и всего.
- Панель открывается только с этого компьютера.
