Журнал

Подключение к Максу

Где взять: business.max.ru → Чат-боты → ваш бот → ⋮ → Настройки → токен. Токен хранится только на этом компьютере.
Запускать бота сразу при открытии программы

Как добавить в чат бригады

  1. Вставьте токен, нажмите «Сохранить», затем «Запустить».
  2. Напишите боту в личку /id — он пришлёт ваш ID. Он же появится на вкладке «Статус» — нажмите «Разрешить».
  3. Добавьте бота в чат бригады. Чат появится в «Ожидают разрешения» — разрешите.
  4. В чате пишите: бот, сколько нужно фитингов… или ответьте на сообщение бота. Список команд — /помощь.

Нейросеть

Ключ — в личном кабинете developers.sber.ru → GigaChat API → «Получить ключ». Для физлиц есть бесплатный лимит. Модели: GigaChat, GigaChat-Pro, GigaChat-Max.
Yandex Cloud → сервисный аккаунт с ролью ai.languageModels.user → API-ключ. Модели: yandexgpt-lite, yandexgpt.
Подходит любой сервис с OpenAI-совместимым API — адрес, ключ и название модели есть в его документации или личном кабинете. Примеры адресов: OpenAI — https://api.openai.com/v1 · DeepSeek — https://api.deepseek.com/v1 · OpenRouter — https://openrouter.ai/api/v1 · Ollama на этом ПК — http://localhost:11434/v1 · LM Studio — http://localhost:1234/v1.

Проверка

Кому бот отвечает

По умолчанию бот отвечает только людям из списка. В общем чате — только если и чат, и человек разрешены. Остальные получат отказ, и их запросы не тратят ваш баланс.
В разрешённых чатах отвечать всем участникам (не только людям из списка)

Кто такой бот

Ещё бот отвечает, если его упомянуть через @ или ответить на его сообщение. Команды со «/» работают всегда.
